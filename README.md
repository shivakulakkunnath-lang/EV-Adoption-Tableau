# EV-Adoption-Tableau


## Project Overview
This Tableau dashboard analyzes electric vehicle (EV) adoption trends and performance metrics across different states, manufacturers, and vehicle models in the United States.

The dashboard provides interactive insights into EV growth, CAFV eligibility, manufacturer performance, and yearly adoption trends using data visualization techniques.

---

## Tools Used
- Tableau
- Excel
- Data Visualization
- Dashboard Design

---

## Dashboard Features
- Total EV vehicle analysis
- Average electric range tracking
- BEV vs PHEV comparison
- State-wise EV adoption map
- Manufacturer-wise vehicle distribution
- Model year trend analysis
- CAFV eligibility analysis
- Interactive filters and slicers

---

## Key KPIs
- Total Vehicles: 150,422
- Total BEVs: 116,750
- Total PHEVs: 33,672
- Average Electric Range: 67.83 Miles

---

## Key Insights
- Tesla is the leading EV manufacturer in the dataset.
- EV adoption has grown significantly in recent years.
- Battery Electric Vehicles (BEVs) dominate compared to Plug-in Hybrid Electric Vehicles (PHEVs).
- Certain states show significantly higher EV adoption rates.
